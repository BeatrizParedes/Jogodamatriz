# 🧩 Exercício React: Matriz Clicável

Este projeto é um exercício simples feito com React. O objetivo é exibir uma matriz interativa onde o usuário pode clicar em qualquer célula para transformá-la em um **"X"**.

## 💡 Objetivo

Praticar os seguintes conceitos do React:

- Estados (`useState`)
- Manipulação de eventos (`onClick`)
- Renderização dinâmica de listas/matrizes
